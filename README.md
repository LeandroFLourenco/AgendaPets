📋 ASP.NET CRUD Demo

Este repositório apresenta uma aplicação simples demonstrando um CRUD (Create, Read, Update, Delete) desenvolvido em ASP.NET Core MVC com integração a banco de dados MySQL.

O objetivo do projeto é servir como exemplo prático para iniciantes e como base para estudos, entrevistas técnicas ou provas de conceito.

🚀 Funcionalidades

📝 Cadastro de registros

📄 Listagem com paginação (se implementado)

✏️ Edição de registros

❌ Exclusão de registros

🔍 Validações básicas de formulário

🗄️ Persistência de dados em banco relacional (MySQL)

🧠 Tecnologias Utilizadas

ASP.NET Core 8.0

C#

Entity Framework Core

MySQL

Razor Views

Bootstrap (opcional)
